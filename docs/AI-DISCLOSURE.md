# AI-assisted development disclosure

These mods were developed with substantial AI assistance using
[OpenAI Codex](https://openai.com/codex/). AI contributed much of the code,
reverse-engineering analysis, patch tooling, native hooks, tests and written
documentation. [Google Gemini](https://gemini.google.com/) also contributed
reverse-engineering reference notes used during development.

rexcraft88 directed feature design, controller behavior and balance choices,
performed hands-on gameplay testing, reported bugs and decided which builds
to release. This does not mean every line received an independent human
code audit. AI-generated work can contain errors; these releases remain
betas with the documented test coverage and limitations.

The release contains code/resource modifications and no new generated audio.
Third-party game resources and tools retain their respective ownership and
licensing requirements; AI use does not replace those credits.

For a GameBanana submission, also complete the site's AI Usage module
accurately. This repository disclosure does not replace that submission step.
