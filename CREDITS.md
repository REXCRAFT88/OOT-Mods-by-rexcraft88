# Credits and scope

Mods and testing direction: rexcraft88. Native patching, tooling and documentation were developed with coding-agent assistance and physical-controller feedback.

These patches target [Project Eglantine](https://github.com/Vampinity/Eglantine-PS5-/tree/ocarina-next13). They are not an official release of that project. Original game content belongs to its respective owners and is supplied locally by the installer user.

Build tools include LLVM/Clang and Python. Installer dependencies are bsdiff4, zstandard, lz4 and zbic; their authors and licenses are recorded in those separately installed packages. This repository retains its existing GPL-3.0 license. No emulator, ROM/NUP, complete game executable, original texture archive, controller device profile or authentication credential is included in the release bundles.
